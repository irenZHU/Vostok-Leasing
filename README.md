# Восток-Лизинг — концепция ребрендинга

Сайт-брендбук по образцу [бренд-системы Яндекс 360](https://360.yandex.ru/brand/).

## Страницы

- `index.html` — «Концепция ребрендинга»: обложка и переключатель направлений 01 / 02 / 03
- `logo.html` — «Логотип и знак»: идея, конструкция знака, логотип, было/стало, версии знака, примеры
- `colors.html` — «Цвета»: пропорции фирменной палитры
- `fonts.html` — «Шрифты»: Onest для заголовков и текста, цвет текста и логотипа

## Как открыть

Сайт статический, его можно открыть через любой локальный сервер. Например:

```
node сервер.mjs
```

и затем http://localhost:8360
